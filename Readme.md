# 🎯 Number Guessing Game

An interactive, multi-mode Number Guessing Game designed and developed by **Kabir Vyas**. This project contains both a **modular C language console program** and a **responsive web application** built with vanilla HTML, CSS, and JavaScript.

## 🚀 Game Modes & Features

- **🎮 Single Player (Solo Challenge):**
  - **Level 1:** Range 1–100 with a 10-attempt limit.
  - **Level 2:** Range 1–1000 with a 15-attempt limit, featuring a rare extreme distance hint when off by more than 500.
  - Directional feedback (*"You guessed it higher"* / *"You guessed it lower"*).

- **👥 Multiplayer Tournament (2–4 Players):**
  - Fast-paced 1–100 range for 2 to 4 players.
  - Sequential rounds with individual score tracking.
  - Formatted final leaderboard crowning the player with the lowest attempts.

- **⚔️ Head-to-Head Duel (1v1 PVP):**
  - Players set secret hidden numbers for each other.
  - Turn-by-turn alternating guesses until the first correct guess wins.

## 🛠️ Tech Stack

- **Console Version:** C Language (modular functions, standard I/O, formatted ASCII presentation)
- **Web Version:** HTML5, CSS3, Vanilla JavaScript (responsive UI, live feedback badges)
